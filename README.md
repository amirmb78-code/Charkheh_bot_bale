# ♻️ چرخه (Charkheh)

**پلتفرم جمع‌آوری پسماند خشک و کالای دسته‌دوم از درب منزل — در سراسر ایران، با ربات بله.**

چرخه یک پایلوت کامل و production-ready است: مشتری هیچ اپلیکیشنی نصب نمی‌کند؛ فقط در **پیام‌رسان بله** عکس کالا را می‌فرستد، برآورد لحظه‌ای قیمت می‌گیرد، موقعیتش را **از روی نقشه** می‌فرستد و زمان مراجعه را هماهنگ می‌کند. ادمین‌ها در همان بله (یا داشبورد وب) قیمت می‌دهند، اعزام را مدیریت می‌کنند و آمار پایلوت را می‌بینند.

## ✨ امکانات

### ربات بله (مشتری)
- ارسال عکس → انتخاب نوع (دکمه شیشه‌ای) → انتخاب وزن تقریبی با دکمه → **برآورد خودکار قیمت** از روی تعرفه روز
- قیمت پیشنهادی ادمین با دکمه **تایید/انصراف**
- انتخاب **استان از بین هر ۳۱ استان** (پوشش سراسری بدون محدودیت؛ محدودسازی قابل پیکربندی است)
- **دکمه «📍 ارسال موقعیت روی نقشه»** (`request_location`) + آدرس متنی + **دکمه «📱 ارسال شماره تماس»** (`request_contact`)
- انتخاب زمان مراجعه با دکمه‌های سریع یا متن دلخواه
- 💳 **کیف پول اعتباری** (`/balance`) — پاداش هر سفارش به‌صورت خودکار واریز می‌شود
- 🎁 **کد دعوت تصادفی** (`/invite`) — پاداش دعوت پس از اولین سفارش تکمیلی فرد دعوت‌شده
- ⭐ **امتیازدهی ۱ تا ۵** پس از هر سفارش تکمیل‌شده
- 🌍 محاسبه و گزارش **کاهش CO₂** هر سفارش
- 💰 تعرفه‌های شفاف (`/prices`) و وضعیت سفارش (`/status`)
- **ارقام فارسی و عربی** در ورودی‌ها کاملاً پشتیبانی می‌شود

### گفتگوی ادمین در بله (چندادمین هم‌زمان)
- اعلان سفارش جدید به **همه ادمین‌ها** (`ADMIN_CHAT_IDS`) همراه با عکس و برآورد سیستم
- پرچم خودکار «⚠️ کم‌ارزش» وقتی برآورد کمتر از حد اعزام است → نوبت جمع‌آوری تجمیعی
- دکمه‌های عملیاتی + **دستورهای سریع متنی** که جریان تک‌اسلاتی را عبور می‌دهند:
  - `قیمت 12 ۸۵۰۰۰` · `رد 12` · `انجام 12` · `وزن 12 ۴.۵` · `مبلغ 12 ۹۲۰۰۰`
- اعلان آماده‌بودن اعزام با **دکمه باز کردن نقشه** (Google Maps) و شماره تماس مشتری
- `/stats` آمار کامل + `/broadcast متن` ارسال پیام گروهی به مشتریان

### داشبورد وب مدیریت
- آمار: نرخ تکمیل، نرخ بازگشت، رضایت (میانگین ⭐)، مجموع خرید/پاداش، مجموع CO₂
- لیست سفارش‌ها با فیلتر وضعیت + صفحه جزئیات (نقشه، تاریخچه رویداد، کیف پول مشتری)
- **اتصال/قطع وب‌هوک از داخل داشبورد** (بدون curl و بدون رمز در URL)
- تنظیم نرخ‌ها و ضریب CO₂، حداقل ارزش اعزام، درصد پاداش، پاداش دعوت، محدوده پوشش استانی
- تغییر دستی وضعیت برای موارد استثنایی

### امنیت و حریم خصوصی
- نشست ادمین = **توکن HMAC امضاشده با انقضا** (نه رمز در کوکی) + rate-limit ورود
- وب‌هوک **بدون سکرت پردازش نمی‌شود**؛ سکرت با `secret_token` به بله اعلام و با هدر اعتبارسنجی می‌شود
- عکس‌ها **خارج از public** ذخیره و فقط از مسیر احرازشده `/admin/media/...` سرو می‌شوند
- مطابق وعده به مشتری: **عکس، آدرس دقیق و شماره تماس پس از پایان سفارش خودکار حذف** می‌شوند
- گارد کامل روی callbackها (مالکیت سفارش، وضعیت مجاز، جلوگیری از لغو/امتیاز تکراری)

## 🚀 راه‌اندازی

پیش‌نیاز: Node.js 20+ و یک PostgreSQL (مثلاً Docker یا سرویس ابری).

```bash
cp .env.example .env        # و مقادیر را پر کنید
npm install
npm run db:push             # ساخت جداول (یا: npm run db:migrate)
npm run build && npm start  # یا: npm run dev
```

سپس وارد `https://YOUR_DOMAIN/admin` شوید و دکمه **«اتصال وب‌هوک»** را بزنید. ربات آماده است ✅

## ⚙️ متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | اتصال PostgreSQL (الزامی) |
| `BALE_BOT_TOKEN` | توکن ربات بله (الزامی) |
| `ADMIN_CHAT_IDS` | چت‌آیدی ادمین‌ها، با ویرگول (الزامی)؛ `ADMIN_CHAT_ID` تکی هم پذیرفته می‌شود |
| `ADMIN_DASHBOARD_PASSWORD` | رمز ورود داشبورد (الزامی) |
| `ADMIN_SESSION_SECRET` | سکرت امضای کوکی نشست (توصیه‌شده؛ `openssl rand -hex 32`) |
| `APP_BASE_URL` | آدرس عمومی سایت (الزامی در سرور) |
| `BALE_WEBHOOK_SECRET` | سکرت وب‌هوک — بدون آن آپدیت‌ها پردازش نمی‌شوند (الزامی) |
| `UPLOAD_DIR` | مسیر ذخیره خصوصی عکس‌ها (پیش‌فرض `./data/uploads/bale`) |

## 🗄 دیتابیس

اسکیما با Drizzle ORM تعریف شده (`src/db/schema.ts`) و مایگریشن‌ها در پوشه `drizzle/` هستند:

```bash
npm run db:generate   # تولید مایگریشن جدید بعد از تغییر اسکیما
npm run db:push       # اعمال سریع (توسعه)
npm run db:migrate    # اعمال مایگریشن‌ها (پروداکشن)
npm run db:studio     # رابط گرافیکی دیتابیس
```

## 🐳 استقرار با Docker

```bash
cp .env.example .env   # مقادیر را پر کنید
docker compose up -d --build
# ساخت جداول (فقط بار اول):
docker compose exec app npx drizzle-kit push
```

سپس `http://SERVER:3000/admin` → ورود → «اتصال وب‌هوک». برای production پشت HTTPS (مثل Nginx/Caddy) قرار دهید و `APP_BASE_URL` را همان دامنه HTTPS بگذارید — بله فقط به وب‌هوک HTTPS وصل می‌شود.

## 📝 نکات عملیاتی

- پشتیبان‌گیری دوره‌ای از `DATABASE_URL` و `UPLOAD_DIR` را فراموش نکنید.
- برای سرویس‌دهی واقعی در سراسر کشور، اعزام در این نسخه «دستی» است: نیروهای میدانی هر استان را چت‌آیدیشان به `ADMIN_CHAT_IDS` اضافه کنید یا بعداً جدول پیک‌ها را بسازید.
- `/api/bale/webhook` آپدیت نامعتبر را 400 و آپدیت بدون امضای معتبر را 401 می‌دهد.
